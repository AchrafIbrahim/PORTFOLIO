# Ibrah Maula Setya Aji - Portfolio Website

A responsive portfolio website built with Vanilla HTML, CSS, and JavaScript.

## 🚀 Live Demo
[Click here to view the live site](https://personal-portfolio.ibrahaji01.workers.dev/) 

## 🛠️ How to Run Locally

If you want to run this project on your local machine:

1. Clone this repository:
   `git clone https://github.com/AchrafIbrahim/PORTFOLIO.git`
2. Open the project folder.
3. Double-click `index.html` to open it in your browser. 
   *(Alternatively, open it with VS Code Live Server).*

## 🧰 Technologies Used
- HTML5 (Semantic tags)
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (DOM Manipulation)
